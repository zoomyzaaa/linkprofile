# My Little Links — Cute / Pastel

เว็บรวมลิงก์โซเชียลมีเดียแบบหน้าเดียว ใช้ HTML/CSS ล้วน ไม่มี dependencies และไม่มีค่าใช้จ่ายในการสร้างไฟล์

## แก้ข้อมูลก่อนเผยแพร่
เปิด `index.html` ด้วย VS Code หรือโปรแกรมแก้ไขข้อความ แล้วค้นหา:
- `YOUR NAME` — เปลี่ยนเป็นชื่อที่แสดง
- `@yourusername` — เปลี่ยนเป็น username
- `href="https://..."` — เปลี่ยนเป็น URL โปรไฟล์จริงของแต่ละแพลตฟอร์ม
- ข้อความใต้ชื่อแพลตฟอร์ม — แก้เป็นคำอธิบายที่ต้องการ

ตัวอย่าง Instagram:
`href="https://instagram.com/yourusername"`
เปลี่ยน `yourusername` ให้เป็นชื่อบัญชีจริงของคุณ

ถ้าไม่ใช้แพลตฟอร์มใด ให้ลบ `<a class="link"> ... </a>` ของแพลตฟอร์มนั้นทั้งชุด

## วิธีเผยแพร่ด้วย Vercel (ไม่ต้องใช้ GitHub)
1. เข้า https://vercel.com/ และสมัคร/เข้าสู่ระบบ
2. เปิด https://vercel.com/new
3. มองหาตัวเลือกอัปโหลดโปรเจกต์/Deploy แบบไม่ใช้ Git หากมีให้เลือก แล้วอัปโหลดโฟลเดอร์โปรเจกต์นี้
4. ตั้งชื่อโปรเจกต์ แล้วกด Deploy
5. เมื่อสำเร็จ Vercel จะแสดง URL ลงท้ายด้วย `.vercel.app`

หมายเหตุ: หน้าตาและตัวเลือกของ Vercel อาจเปลี่ยนแปลงได้ หากบัญชีของคุณไม่มีตัวเลือกอัปโหลดโฟลเดอร์โดยตรง ให้ใช้วิธี GitHub ด้านล่าง

## วิธีสำรองที่เชื่อถือได้: GitHub + Vercel
1. เข้า https://github.com/ แล้วสร้างบัญชีถ้ายังไม่มี
2. กด New repository ตั้งชื่อเช่น `my-little-links` และเลือก Public หรือ Private
3. อัปโหลด `index.html` ไปที่ repository (Add file → Upload files → Commit changes)
4. เข้า https://vercel.com/new และเชื่อมต่อ GitHub
5. เลือก repository `my-little-links`
6. สำหรับ HTML/CSS ล้วน ไม่ต้องมี Build Command; หากมีช่อง Output Directory ให้ใช้ค่าเริ่มต้นหรือปล่อยว่างตามที่หน้าเว็บแนะนำ
7. กด Deploy และเปิด URL ที่ได้รับ
8. ครั้งต่อไปที่แก้ `index.html` และ commit ขึ้น GitHub, Vercel จะ deploy เวอร์ชันใหม่อัตโนมัติ

## เช็กก่อนแชร์
- คลิกลิงก์ทุกปุ่มจากหน้าเว็บที่เผยแพร่แล้ว
- ตรวจบนมือถือ
- เปลี่ยน URL ตัวอย่างทุกอันให้เป็นลิงก์จริงก่อนแชร์
- Discord ในตัวอย่างเป็นลิงก์ทั่วไป; หากต้องการชวนเข้าห้อง ให้แทนที่ด้วย invite link ของคุณ
